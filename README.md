🎓 Projet de Groupe : Presentation Test

📝 Introduction

Ce dépôt (repository) contient les travaux officiels pour le projet de groupe dans le cadre du cours de Techniques de programmation(Python), 
Infrastructures de données et introduction à la science des données(SQL),
Econométrie appliquée à l'université de Strasbourg.

Ce projet se concentre sur **objectif principal : la conception, l'évaluation et le test d'un système de présentation de données
,la mise en pratique de scénarios de tests pour une présentation**.

🎯 Objectifs du projet
- Appliquer les connaissances théoriques pour résoudre un problème concret :
    - Proposer et appliquer des modèles économétriques adaptés à un projet d’analyse de données en utilisant R (RStudio),
     en sélectionnant les méthodes d’estimation les plus pertinentes selon la problématique étudiée.
    - Concevoir et automatiser des tests du système à l’aide de Python afin de garantir la fiabilité et la robustesse des résultats.
    - Exploiter les langages de bases de données et SQL pour structurer, interroger et analyser les données afin de répondre aux besoins décisionnels des entreprises.
- Développer des compétences en travail d'équipe, en gestion des tâches et en contrôle de version avec Git/GitHub.
- Rechercher, concevoir et exécuter avec succès des scénarios de test.

🛠 Technologies utilisées (Tech Stack)
- Langages : R,Python,SQL 
- Outils de test : RStudio, Jupyter Notebook, MySQL, DBeaver
- Outils de gestion : Git, GitHub
